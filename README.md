# Hybrid Chatbot with Gemini + ChromaDB + Streamlit

This project is a Google Services Support Chatbot powered by:

- Gemini via Google Generative AI (genai SDK)
- ChromaDB for semantic document retrieval
- LangChain to build RAG pipelines
- Streamlit Authenticator for secure login
- Firebase Firestore for chat logging
- PDF uploading to build a custom knowledge base

## Prerequisites

1. Gemini API Key  
   Get it from: https://makersuite.google.com/app/apikey

2. Python 3.10 or above
